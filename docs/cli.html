Команда heardlyThe heardly command

Та же модель, но из терминала: расшифровать файл одной строкой, прогнать папку циклом или встроить расшифровку в свой скрипт.The same model, from the terminal: transcribe a file in one line, run a folder through a loop or wire transcription into a script of your own.

Функция ProA Pro feature

Команда работает при активной подписке Pro или в пробный период.The command works with an active Pro subscription or during the trial.

УстановкаInstalling

Откройте Настройки → Система и нажмите «Установить» в строке «Команда в терминале». После этого heardly доступна в любом окне терминала.

Open Settings → System and press Install in the “Terminal command” row. After that, heardly is available in any terminal window.

Как пользоватьсяUsage

heardly <файл> [опции]
heardly <file> [options]
ОпцияOption Что делаетWhat it does
-s, --speakersРазмечает говорящих: кто из них произнёс реплику.Labels the speakers: who said which line.
-t, --timecodesДобавляет таймкоды.Adds timecodes.
-f, --formattxt (по умолчанию), (default), srt, json
-o, --outputСохранить в файл вместо вывода на экран.Write to a file instead of printing to the screen.
-h, --helpПоказать справку.Show the help.

ПримерыExamples

Расшифровать запись и посмотреть текст прямо в терминале:

Transcribe a recording and read the text right in the terminal:

heardly ~/Downloads/call.m4a

Субтитры к видео с разметкой говорящих:

Subtitles for a video, with speakers marked:

heardly webinar.mp4 -s -f srt -o webinar.srt

Прогнать всю папку с записями:

Run a whole folder of recordings:

for f in ~/Calls/*.m4a; do
  heardly "$f" -t -o "${f%.m4a}.txt"
done

Про разметку говорящихAbout speaker labels

Флаг -s разделяет голоса по звучанию, а не по источнику звука. Это работает только в терминале: в самом приложении разметки говорящих сейчас нет, там реплики делятся на «Я» и «Компьютер» по тому, откуда пришёл звук.

Модель для разметки скачивается при первом запуске с флагом, дальше работает офлайн. Если разделить голоса не удалось, команда честно скажет об этом и отдаст текст без подписей.

The -s flag separates voices by how they sound, not by where the audio came from. This works in the terminal only: the app itself has no speaker labels at the moment, and splits lines into “Me” and “Computer” by audio source instead.

The model for this is downloaded the first time you use the flag and works offline afterwards. If the voices cannot be separated, the command says so plainly and returns the text without labels.
